# MODEL 600 GUI デザイン v2「実機ハードウェア」案（Step 1）

状態：**提案中**。見本（Step 2）の承認後に Qt 実装（Step 3）へ進む。

## 1. ねらい

SNS に画像が流れてきたときに「なにこれ、かっこいい」と手が止まる見た目にする。参考にしたのは、実機をそのまま画面に再現した系統のプラグイン（UAD 1176 / LA-2A、M Media Audio Room Service など）。共通点は次の4つ。

- 前面パネルが「機材そのもの」に見える（ラック耳、ネジ、刻印された文字）。
- 中央に、暖色に光るアナログ VU メーター（針が振れる）。
- 周囲に目盛りが印刷された、大きく厚みのあるつまみ。
- トグルスイッチ、パイロットランプ、光る押しボタンといった物理部品。

**他社のロゴ・配色・パネル意匠はまねない**。SEVENTHWELL 独自の「1960年代の放送局用レベリングアンプ」として設計する（製品名の由来 Fairchild 600 の時代感）。

## 2. 見た目の方針

| 要素 | 方針 |
|---|---|
| パネル | ヘアライン加工のチャコール色アルミ（陽極酸化）。左右にラック耳と長穴、プラスネジ |
| 文字 | パネルに印刷されたオフホワイトの刻印。ブランド名だけ SEVENTHWELL アンバー |
| VU メーター | クリーム色の文字盤を背面から暖色で照らす。0 VU から上は赤帯。ガラス越しの映り込み |
| 大つまみ | 入力・出力用。黒いローレット（滑り止め）付きスカート＋削り出しアルミのキャップ＋白い指示線 |
| 小つまみ | 段階切替（キャラクター、空間エフェクト）。黒いベークライト調、先端が尖った指示形状 |
| スイッチ | クロームのトグルスイッチ（オートモノ、先読み 1.5 ms / 0 ms） |
| ボタン | 光る角型押しボタン（自動測定、A/B 試聴、ピー音、咳ミュート） |
| ランプ | 電源の赤い宝石ランプ、ユニット連携の小さな緑ランプ ×5 |

## 3. 画面サイズ

- 従来の 560 × 560 を、横長のラック機材比率 **1100 × 480** に変える（実機らしさのため）。
- [05] 統合ミキサーは、承認後に同じ意匠で 4ch 分の VU メーターを並べる形で設計する。

## 4. 実装方法（承認後）

- パネル背景、つまみ、スイッチ、メーターの部品はすべて Blender でレンダリングする。
- つまみは回転角ごとのコマ（フィルムストリップ）を書き出し、Qt では角度に応じたコマを表示する。プラグイン業界の標準的な手法で、光の当たり方が回転しても正しく保たれる。
- VU メーターの針と数値表示は Qt が描画し、毎フレームの負荷を抑える。

## 6. 見本で決めた細部

| 項目 | 内容 |
|---|---|
| パネルの筋目 | 横方向のヘアライン。出力1画素ほどの太さにして、縮小表示でも筋が残るようにした |
| 大つまみのキャップ | 同心円の切削溝＋放射状の異方性反射（回すと光の筋が回る） |
| 押しボタン | 消灯時は暗い色付きガラス、点灯時は内側から発光。点灯と消灯がひと目で分かる明暗差にした |
| 電源ランプ | 赤い宝石状のレンズ（屈折＋弱い発光） |
| VU メーター | 文字盤を背面照明、針は Qt 描画（見本は -1 VU の位置） |
| ライティング | 左上から細長い暖色のストリップ光、右下から寒色の弱い補助光、奥から白い縁取り光 |
