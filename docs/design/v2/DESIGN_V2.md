## 1. ねらい

SNS に画像が流れてきたときに「なにこれ、かっこいい」と手が止まる見た目にする。参考にしたのは、実機をそのまま画面に再現した系統のプラグイン（UAD 1176 / LA-2A、M Media Audio Room Service など）。共通点は次の4つ。

- 前面パネルが「機材そのもの」に見える（ラック耳、ネジ、刻印された文字）。
- 中央に、暖色に光るアナログ VU メーター（針が振れる）。
- 周囲に目盛りが印刷された、大きく厚みのあるつまみ。
- トグルスイッチ、パイロットランプ、光る押しボタンといった物理部品。

**他社のロゴ・配色・パネル意匠はまねない**。SEVENTHWELL 独自の「1960年代の放送局用レベリングアンプ」として設計する（製品名の由来 Fairchild 600 の時代感）。

## 2. 見た目の方針

| 要素 | 方針 |
|---|---|
| パネル | ヘアライン加工のチャコール色アルミ（陽極酸化）。左右にラック耳と長穴、プラスネジ |
| 文字 | パネルに印刷されたオフホワイトの刻印。ブランド名だけ SEVENTHWELL アンバー |
| VU メーター | クリーム色の文字盤を背面から暖色で照らす。0 VU から上は赤帯。ガラス越しの映り込み |
| 大つまみ | 入力・出力用。黒いローレット（滑り止め）付きスカート＋削り出しアルミのキャップ＋白い指示線 |
| 小つまみ | 段階切替（キャラクター、空間エフェクト）。黒いベークライト調、先端が尖った指示形状 |
| スイッチ | クロームのトグルスイッチ（オートモノ、先読み 1.5 ms / 0 ms） |
| ボタン | 光る角型押しボタン（自動測定、A/B 試聴、ピー音、咳ミュート） |
| ランプ | 電源の赤い宝石ランプ、ユニット連携の小さな緑ランプ ×5 |

## 3. 画面サイズ

- 従来の 560 × 560 を、横長のラック機材比率 **1100 × 480** に変える（実機らしさのため）。
- [05] 統合ミキサーは、承認後に同じ意匠で 4ch 分の VU メーターを並べる形で設計する。

## 4. 実装方法（承認後）

- パネル背景、つまみ、スイッチ、メーターの部品はすべて Blender でレンダリングする。
- つまみは回転角ごとのコマ（フィルムストリップ）を書き出し、Qt では角度に応じたコマを表示する。プラグイン業界の標準的な手法で、光の当たり方が回転しても正しく保たれる。
- VU メーターの針と数値表示は Qt が描画し、毎フレームの負荷を抑える。

## 9. [02]〜[05] の見せ方（Step 1）

### 9.1 共通ルール：「何をしているか」が見える

1. **番号プレート**：ロゴの右に色付きのエナメル板（01 アンバー／02 青緑／03 赤／04 緑／05 真鍮）。ラックに並べても、配信中に小さく映っても、どのユニットか一瞬で分かる。[05] の各チャンネル名にも同じ色を使い、対応を目で追えるようにする。
2. **主役のメーターをユニットごとに変える**：同じ形のパネルが並んでも見分けが付くように、中央の計器で役割を表す。
3. **動作ランプ**：「今この瞬間に何をしているか」を、平易な英語のランプ名で示す（YOU TALK、LIMIT、VOICE DUCK など）。ランプが点いた理由がそのまま読める。
4. **パネル文字は英語の刻印**：実機らしさを保つ。日本語の説明はマウスを乗せたときの説明表示と、言語切替で出す。

## 10. メーターをデジタル表示に変更（Step 1）

アナログ VU の針は「今いくつなのか」が読み取りにくい、というご指摘を受けた変更。全ユニットのメーターを、[05] 上段と同じ系統のデジタル表示窓に置き換える。続くご指摘で、主表示を LUFS から dBFS に改めた。

### 10.1 表示の単位：dBFS が主、LUFS は補助

OBS の音量ミキサーは各ソースを dBFS で表示する。配信者が見慣れた単位に合わせ、大きな数字とバーはピーク dBFS にする。LUFS は右上の補助表示と [05] の上段に回す。

| 段 | 内容 | 例 |
|---|---|---|
| 上段 | 何の値か（左）と補助の値（右） | PEAK ／ SHORT-TERM -13.6 LUFS |
| 中段 | 大きな7セグ数字と単位 | -6.2 dBFS |
| 下段 | 同じ値の LED バー（-60〜0 dBFS）、ピークホールド1セグメント、目盛り | -60 -40 -30 -20 -9 0 |

- **色分け**：OBS の初期値に合わせ、-20 dBFS 未満が緑、-20〜-9 がアンバー、-9 以上が赤。出典は obs-studio の `frontend/components/VolumeMeter.cpp` で、minimumLevel -60、warningLevel -20、errorLevel -9、clipLevel 0。
- **中央0のバー**：[02] の自動補正（-12〜+12 dB）と [05] の位相（-1〜+1）。中央から左右に点灯し、下げる側・逆相側は赤。
- **消灯セグメント**：実機の7セグ・LED と同じく、暗く透けて見える。

### 10.2 ユニット別

| ユニット | 窓 | 大きな数字とバー | 補助表示 |
|---|---|---|---|
| [01] | 1つ（320 × 184） | 出力のピーク dBFS | 短期 LUFS |
| [02] | 2つ（220 × 152） | 左：相手の声のピーク dBFS。右：自動補正量 dB | 左に短期 LUFS |
| [03] | 1つ | ゲーム音のピーク dBFS | 短期 LUFS。下の「LIMITING」LED バーはそのまま |
| [04] | 1つ | BGM のピーク dBFS | 短期 LUFS。下の「POCKET」LED バーはそのまま |
| [05] | 4ch 分（216 × 148）＋位相（168 × 104） | 各ユニットのピーク dBFS ／ 相関値 | 各 ch の短期 LUFS |
| [05] 上段 | 3窓 | 全体（マスター）のピーク dBFS、短期 LUFS、統合 LUFS | |

### 10.3 実装メモ（Step 3）

- **7セグ数字・LED バー**：Qt の QPainter で描画する。消灯セグメントも描き、点灯部分だけに光のにじみを付ける。
- **ベゼル・ガラス**：Blender で描いた画像を使う。
- **見本の描画**：窓の中身は放射のみの材質と、反射だけを足す薄いガラスで描く。描画ノイズが出ない。
