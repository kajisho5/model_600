# MODEL 600 — ロゴ（Step 1 設計 / Step 2 案）

状態：**案の選択待ち**（A〜C はアイコン由来、D〜F はソフトの画面由来。推奨は D）。選ばれた案だけを仕上げる（色、白・黒版、README 見出し用のワードマーク、ファビコン類）。

## 前提

- シンボル（記号）は承認済みのアプリアイコン（案 A「ダイヤル」：270° のレベル弧、つまみの円、指針）を 1 色に描き直して使う。新しく作るのは**ワードマーク（文字のロゴ）とシンボルとの組み合わせ**。
- 使う場所は GitHub README の見出し、配布 dmg の窓、Web ページ、プラグイン画面のヘッダー。小さいサイズ（ファビコン、32 px 以下）はシンボルだけを使う。
- 文字はフォントを使わず、図形（線と円）で組んでいる。GitHub はフォントを読み込まないので、どこでも同じ見た目になる。

## 方向性

| 項目 | 内容 |
|------|------|
| 言葉 | 放送機材、正確、落ち着き、プロ向け、ハードウェア |
| この分野の定番（避けるもの） | 波形、ヘッドホン、マイク、イコライザーの棒、音の輪 |
| 差別化 | つまみ（ダイヤル）をシンボルにし、製品名「600」の 0 とつなげる |

## 案

| 案 | 内容 | 長所 | 短所 |
|----|------|------|------|
| A つまみの 0（推奨） | 丸い端の一定の線。600 の最後の 0 につまみの指針が入る | 名前そのものが「つまみ」になり、シンボルと文字が一つの考えでつながる | 0 の中の指針は小さいサイズで消える（小さいときはシンボルを使う） |
| B パネルのバッジ | 小さく字間を広げた MODEL の下に太い 600。機材の銘板のような 2 段組み | 「600」が強く、覚えやすい | 2 段なので横長の場所（ヘッダー）では小さくなる |
| C 刻印 | 横に広い文字、切りっぱなしの線端、広い字間。パネルのシルク印刷風 | 高級機材らしい落ち着き | 線が細く、小さいサイズや暗い背景に弱い |

プレビュー：`preview/concepts.png`（一覧）、`preview/*_lockup.png`、`preview/*_wordmark.png`。

## 画面から作った案（D〜F）

GUI v2 のパネルには、すでにブランドの表示（名札）がある。上にアンバーで字間を広げた SEVENTHWELL、その下に Inter Bold の太い MODEL 600、横にアンバーのユニット番号札。ほかに、消えている部分まで見えるアンバーの 7 セグ表示と、チャコールのアルミパネルがある。D〜F はこれをそのままロゴにした案。色は `src/ui-theme.hpp`、書体は `resources/fonts` の Inter で、画面と同じにしている。Inter は SIL OFL 1.1 で、ロゴへの使用も認められている。文字は図形に変換して収録している。

| 案 | 内容 | 長所 | 短所 |
|----|------|------|------|
| **D 名札（推奨）** | SEVENTHWELL ／ MODEL 600 ／ アンバーの札（中にダイヤル）／ 線 ／ BROADCAST SUITE | 製品画面と同じ見た目なので、README・dmg・プラグイン画面で一貫する。白黒どちらの背景でも読める | 札の中のダイヤルは小さいサイズで見えにくい（小さいときはアプリアイコンを使う） |
| E 7 セグ | 表示窓の中に、アンバーの 7 セグで描いた「600」と、ラベルの MODEL | 製品のメーター表示そのもので、正方形に近く、SNS のアイコンなどにも使える | 7 セグはよくある表現なので、名札（D）と組み合わせて使う前提 |
| F パネル | ラックの耳と長穴が付いた小さなパネルに名札を刻印 | 「ラック機材」であることがすぐ伝わる | D とほぼ同じ要素で、外枠のぶん小さく見える |

ライト版の SEVENTHWELL は濃いアンバー（#A8620F、白地で 4.75:1）にする。画面と同じアンバー（#F0A33A）は白地で 2.1:1 しかなく、小さい文字では読みにくい。

プレビュー：`preview/gui_concepts.png`（D〜F、ダーク／ライト）。生成：`python3 make_gui_logo.py && ./render.sh`（fontTools が要る）。

## 次（選んだ後）

1. 選んだ案を仕上げる：光学補正、字間の調整、小さいサイズ用の形
2. 色：アンバー（#F0A33A）を指針・レベル弧に、文字は黒（ライト）／白（ダーク）
3. 書き出し：`brand/` に README 用ワードマーク（黒・白）、シンボル、横組み・縦組み
4. README の冒頭をアイコン＋ワードマーク＋一言説明＋リンク＋バッジ＋画面写真の見出しにする

再生成：`python3 make_logo.py && ./render.sh`（このフォルダで実行）
