# MODEL 600 GUI リデザイン設計書（Step 1）

対象：スタジオコンソール（[01]〜[04] 共通の単体画面）、[05] 統合ミキサー、MINI 表示、10秒自動測定モーダル。
状態：**設計段階**。SVG デザイン（Step 2）の承認後に Qt 実装（Step 3）へ進む。

## 1. 目的と方針

市販プラグインとして通用する、落ち着いたハードウェア調の見た目にする。「AIっぽさ」を生んでいた要素を取り除く。

| 現状の問題 | 方針 |
|---|---|
| 絵文字（🎤 🤬 📌 ⚡ 💡 など）がボタンや案内文に入っている | **全廃**。必要な箇所だけ自前のベクター線アイコン（3種）を QPainter で描く |
| Qt 標準のコンボボックス・スライダーがそのまま見える | 選択肢は**セグメント切替**、音量系は**自前描画のフェーダー**に置き換える |
| 原色に近い蛍光グリーンの LED メーター | 彩度を落とした3色ゾーン＋**dB 目盛り付き**メーター |
| `[01] VOCAL MASTER` のような角括弧表記 | 番号は小さな**ユニットバッジ**、名称は字間を空けた大文字 |
| 文字の大きさ・太さがばらばら | 5段階のタイプスケールに統一。数値は**等幅数字**（tabular-nums） |
| 光沢のある金属グラデーション | **つや消し**の濃いグラファイト。ラック耳とネジは控えめに残す（仕様の19インチラック意匠） |
| 案内メッセージが本文の途中に浮く | 画面下部の**ステータス行**に、色付きの小さなドット＋短文で集約 |

### 2.2 タイポグラフィ

- 欧文・数字：**Inter**（数値は `tabular-nums`）。和文：**Noto Sans JP**。
- 両フォントとも SIL Open Font License。Qt リソースとして同梱し、OS による見た目の差をなくす。

| 段階 | サイズ / 太さ | 用途 |
|---|---|---|
| Display | 22px / Medium | [05] マスターのラウドネス値 |
| Title | 15px / Bold, 字間 1px | 製品名 `MODEL 600` |
| Body | 12px / Medium | キーの文字、ユニット名 |
| Label | 9.5px / SemiBold, 大文字, 字間 1.2px | 区画ラベル（`OUTPUT`、`CHARACTER` など） |
| Scale | 9px / Regular | メーター・フェーダーの目盛り |

### 2.3 寸法

- 角丸：パネル 6px、キー 4px、バッジ 3px。
- 線：すべて 1px。影は使わない。モーダルのみ外周に影。
- 余白の基本単位：4px。区画の間隔は 16px。

## 3. 部品（コンポーネント）

| 部品 | 仕様 | Qt 実装 |
|---|---|---|
| キー | 高さ 32px。トグル系は左に 6px の LED（消灯 `#3A4047`／点灯色）。押下中は `raised.active` | `QPushButton` の自前描画サブクラス `RackKey` |
| 非常用キー | ピー音＝赤 LED、咳ミュート＝アンバー LED。押している間だけ点灯 | `RackKey`（モーメンタリ） |
| セグメント切替 | 高さ 28px。選択中は `raised.active` 地＋下辺 2px のアンバー線 | 新規 `SegmentedControl`（`QComboBox` を置換） |
| 縦メーター | 3px 刻みのセグメント（1px 間隔）。上に数値ボックス（クリックでホールド解除）。横に dB 目盛り | `LedMeter` を全面改修 |
| メーター目盛り | 0, −3, −6, −9, −12, −18, −24, −36, −48, −60 | 区分線形の目盛り則：0 dB=100%、−6=80%、−12=62%、−18=48%、−24=37%、−36=20%、−48=8%、−60=0%（配信で使う上側 12 dB に高さの約38%を割り当てる） |
| GR メーター | 上から下へ伸びる青。目盛り 0〜−24 dB | `LedMeter`（GR モード） |
| 縦フェーダー | 4px の溝＋目盛り（+12〜−∞）＋ 32×14px のキャップ（中央に白線）。下に数値ボックス | `TrimFader` を自前描画に変更 |
| 横フェーダー | 同じ意匠の横向き。右に数値ボックス | 同上 |
| 数値ボックス | `panel` 地。上に Label、下に値（等幅数字）、単位は値の直後に小さく続ける | 新規 `Readout` |
| ユニットバッジ | 26×22px、アンバー 1px 枠、番号 | ヘッダー内で描画 |
| LINK 表示 | 6px の LED ドット×5（01〜05）。リンク中は緑、未接続は消灯 | ヘッダー内で描画 |
| アイコン | ピン留め、折り畳み、リセットの3種のみ。14px、線幅 1.5px、`text.2` | `QPainterPath` で描画（画像ファイル・絵文字は不使用） |
| ステータス行 | 高さ 28px。色付きドット＋短文。右端に動作情報（サンプルレート等） | 新規 `StatusLine` |
| アップデート表示 | ヘッダー2行目の右端（ボタンの真下）に、アンバー枠の小さな表示「UPDATE 1.1.0」。新版があるときだけ出す | ヘッダー内で描画 |

## 4. 画面構成

### 4.1 スタジオコンソール（[01] VOCAL MASTER）— 560 × 560px

```
┌ラック耳┬───────────────────────────────────────────────┬ラック耳┐
│  ○    │ SEVENTHWELL   [01] VOCAL MASTER        ピン 折畳 JA|EN 戻す │
│       │ MODEL 600     LINK ●01 ●02 ●03 ●04 ●05                │
│       ├───────────────────────────────────────────────┤
│       │ OUTPUT     TRUE PEAK │ SHORT-TERM │ INTEGRATED │ INPUT GAIN│
│       │ [-2.2][GR]                                              │
│       │ ┃  0 ┃     CHARACTER  [SOFT/ASMR | BROADCAST | FPS/LOUD]  │
│       │ ┃ -6 ┃     SPACE FX   [DRY|KARAOKE|BATH|HALL|CAVE|RADIO]  │
│       │ ┃-12 ┃     測定・試聴   [10秒 自動測定] [A/B 試聴]          │
│       │ ┃-24 ┃     非常用       [ピー音 1kHz]  [咳ミュート]          │
│       │ ┃-60 ┃     OUTPUT TRIM ━━━━━━━━■━━━━━━  [0.0 dB]       │
│       ├───────────────────────────────────────────────┤
│  ○    │ ● 動作中 · 先読み 1.5 ms               48 kHz · 2 ch  v1.0.0 │
└───────┴───────────────────────────────────────────────┴───────┘
```

- [02]〜[04] も同じ骨格。中段の操作部だけがユニット固有になる（例：[04] は M/S ポケット深さ、歌枠セーフ、AFK スウェル）。

### 4.2 [05] 統合ミキサー — 1120 × 560px

- 左：4本のチャンネルストリップ（01 VOCAL / 02 COLLAB / 03 GAME / 04 BGM）。各ストリップは、ピーク数値、レベルメーター、ダッキング量メーター、短期ラウドネス、リモートフェーダー＋数値ボックス。
- 右：仮想マスター合算。M / S / I のラウドネス大表示、YouTube 目標帯（−12.0 ± 1.5 LUFS）を帯グラフで表示、位相相関計、モノラル確認キー、シーン切替（4択セグメント）、チャプター記録とカルテ出力のキー。
- 認証解除ボタンは主画面から外し、ステータス行右端の控えめな「ライセンス」項目に移す。中身の設計は保留（`docs/DEFERRED_NOTES.md`）。

### 4.3 MINI 表示 — 高さ 120px（[01]：560px 幅、[05]：1120px 幅）

- 1行のコンパクトなヘッダー（`MODEL 600` とユニット名のみ）＋横向きメーター（目盛り付き）＋数値。[01] は TP / S / GR、[05] は M / S / I / TP。

### 4.4 10秒自動測定モーダル — 560 × 400px

- 3段階表示（準備 → 測定 → 結果）。
- 測定中：読み上げ文のカード、入力レベルの横メーター、進捗バーと経過秒数（例 `04.0 / 10.0 秒`）。
- 結果は左端の色帯で種類を区別：成功（緑）、入力の歪み（赤）、声を検出できず（アンバー）。
- 成功時は、推奨入力ゲイン・基準ピーク・想定ラウドネスの3値と、オーディオインターフェースの GAIN つまみの目安位置を図で示す（絵文字ではなく、つまみの線画）。

## 5. 文言の方針

- 区画ラベル・単位は英語のまま（`TRUE PEAK`、`LUFS` など）。業務用機材と同じ慣習に合わせる。
- 操作ボタン・案内文は表示言語（JA / EN）に従う。
- 案内文は感嘆符や記号を使わず、1文で要点だけを書く。

## 8. 承認していただきたい点

1. 色とフォントの方針（つや消しグラファイト、アンバーは選択中だけ、Inter と Noto Sans JP を同梱）。
2. コンボボックスをセグメント切替に置き換えること。
3. 認証解除ボタンを主画面から外し、ステータス行に移すこと。
4. 区画ラベルを英語、操作ボタンを表示言語に合わせる文言方針。
